# projectone web

Živě: https://plecitykuba4-bot.github.io/projectone-web/

## Jak na tom pracujeme ve třech

Nic se nestahuje. Všechno jede přes prohlížeč:

1. Otevři **https://claude.ai/code** a při prvním spuštění propoj svůj GitHub.
2. Vyber repozitář `plecitykuba4-bot/projectone-web`.
3. Napiš Claudovi, co chceš změnit. Třeba: „V sekci Cena přidej třetí balíček“.
4. Claude změnu udělá na vlastní větvi a uloží ji na GitHub. Pak z ní jedním klikem uděláš **Pull Request**.
5. Někdo z ostatních se na PR podívá a dá **Merge**. Do dvou minut je změna na živém webu.

## Jedno hlavní pravidlo

**Každý dělá na jiné sekci.** Než začneš, napiš ostatním, na čem děláš (hero, služby, cena, kontakt…). Dva lidi ve stejné sekci najednou = konflikt.

Pravidla pro Clauda, tedy strukturu webu, styl a postup, jsou v [CLAUDE.md](CLAUDE.md). Každý Claude si je přečte sám.
